# API Reference

## Conventions

### Base URL
```
Local:      http://localhost:8000
Staging:    https://lakhimpur-staging.railway.app
Production: https://your-api.railway.app
```

### Authentication
Owner-only endpoints require a valid JWT cookie set by `POST /api/auth/login`.
The cookie is sent automatically by the browser on every request.
Public endpoints (shop, order tracking) require no authentication.

### Money fields
All money values in requests: **string or Decimal** — never float.
All money values in responses: **string with 5 decimal places** — e.g. `"105.00000"`.

### Standard error response
```json
{
  "error":      "STOCK_INSUFFICIENT",
  "message":    "Only 3.5kg available for Joha Rice",
  "field":      "quantity",
  "detail":     { "available_qty": "3.500", "requested_qty": "5.000" },
  "status":     422,
  "request_id": "abc123-xyz789"
}
```

### Idempotency
All `POST` mutation endpoints accept `idempotency_key` (UUID generated by client).
Send the same key again to get the same response without side effects.

## Auth

### POST /api/auth/login
Login and receive JWT cookie.

**Access:** Public

**Request:**
```json
{ "username": "admin", "password": "your_password" }
```

**Response 200:**
```
Set-Cookie: token=eyJhbGc...; HttpOnly; Secure; SameSite=Strict; Max-Age=86400
```
```json
{ "owner_id": "uuid", "username": "admin", "expires_at": "2025-05-11T10:30:00Z" }
```

**Errors:**
| Code | Error | When |
|---|---|---|
| 401 | `INVALID_CREDENTIALS` | Wrong username or password (same error — prevents enumeration) |
| 422 | `VALIDATION_ERROR` | Empty username or password |
| 429 | `RATE_LIMIT_EXCEEDED` | > 5 attempts/min from same IP |

---

### POST /api/auth/logout
Invalidate JWT and clear cookie.

**Access:** Owner only

**Request:** No body (reads JWT from cookie)

**Response 200:**
```
Set-Cookie: token=; Max-Age=0
```
```json
{ "message": "logged out" }
```

---

### POST /api/auth/refresh
Issue a fresh token before the current one expires.

**Access:** Owner only

**Request:** No body

**Response 200:**
```json
{ "expires_at": "2025-05-12T10:30:00Z" }
```

### POST /api/inventory/entries
Record any stock movement. The ledger entry that drives P&L.

**Access:** Owner only

**Request:**
```json
{
  "idempotency_key": "uuid-client-generated",
  "product_id":      "uuid",
  "entry_type":      "purchase",
  "qty":             "50",
  "unit_cost":       "72",
  "total_amount":    "3600",
  "source":          "external",
  "date":            "2025-05-10",
  "note":            "Bought from Guwahati market"
}
```

**Entry types:**
| Type | Direction | P&L impact |
|---|---|---|
| `sale` | out | Revenue |
| `purchase` | in | COGS (purchased) |
| `wastage_normal` | out | COGS (normal loss — absorbed) |
| `wastage_abnormal` | out | Below-gross loss (abnormal) |
| `consumption` | out | COGS (own use) |
| `opening_stock` | in | COGS baseline |
| `closing_stock` | out | COGS deduction |
| `production` | in | From milling/petha batch |
| `fixed_cost` | out | OpEx |
| `provision` | out | OpEx (accrued) |
| `capex` | in | Asset purchase (not expense) |

**Response 201:**
```json
{
  "id":             "uuid",
  "product_id":     "uuid",
  "entry_type":     "purchase",
  "qty":            "50.000",
  "unit_cost":      "72.00000",
  "total_amount":   "3600.00000",
  "price_variance": null,
  "cost_variance":  "-400.00000",
  "new_stock_qty":  "97.500",
  "date":           "2025-05-10"
}
```

## Orders

### POST /api/orders/
Create an order. Offline orders confirm immediately. Online orders wait for webhook.

**Access:** Public (customers can order) + Owner (offline orders)

**Request:**
```json
{
  "idempotency_key":  "uuid-client-generated",
  "customer_name":    "Ratan Das",
  "customer_phone":   "+919876543210",
  "customer_address": "Ward 5, Lakhimpur town",
  "fulfillment_type": "pickup",
  "channel":          "online",
  "payment_mode":     "razorpay",
  "items": [
    { "product_id": "uuid", "qty": "3", "source": "own" },
    { "product_id": "uuid", "qty": "4", "source": "own" }
  ]
}
```

**Payment modes:**
| Mode | Channel | Behaviour |
|---|---|---|
| `razorpay` | online | Returns `razorpay_order_id`. Stock decremented on webhook. |
| `cash` | offline | Confirmed immediately. Stock decremented. |
| `upi_manual` | offline | Confirmed immediately. Stock decremented. |
| `credit` | offline | Confirmed immediately. Payment status = outstanding. |

**Response 201:**
```json
{
  "id":               "uuid",
  "order_number":     "LKP-2025-0042",
  "status":           "pending",
  "channel":          "online",
  "fulfillment_type": "pickup",
  "customer_name":    "Ratan Das",
  "customer_phone":   "+919876543210",
  "total_amount":     "595.00000",
  "final_amount":     "595.00000",
  "razorpay_order_id":"order_xxx",
  "cancel_reason":    null,
  "created_at":       "2025-05-10T10:30:45Z",
  "items": [
    {
      "product_id":   "uuid",
      "product_name": "Joha Rice",
      "unit_price":   "105.00000",
      "qty":          "3.000",
      "total":        "315.00000",
      "source":       "own"
    }
  ],
  "payment": { "mode": "razorpay", "status": "pending", "amount": "595.00000" }
}
```

**Errors:**
| Code | Error | When |
|---|---|---|
| 422 | `STOCK_INSUFFICIENT` | Order qty > current stock |
| 422 | `PRODUCT_INACTIVE` | Product is inactive |
| 404 | `PRODUCT_NOT_FOUND` | Unknown product_id in items |
| 503 | `RAZORPAY_ORDER_CREATE_FAILED` | Razorpay API error |

---

### GET /api/orders/

**Access:** Owner only

**Query params:**

```
status    string   Filter by status (pending/confirmed/packed/...)

```

---

### GET /api/orders/{order_id}
Get a single order by UUID.

**Access:** Public — customer tracks own order by UUID (no guessing possible).

---

### PATCH /api/orders/{order_id}/status
Update order status. Enforces state machine transitions.

**Access:** Owner only

**Request:**
```json
{
  "status":        "packed",
  "cancel_reason": null
}
```

**Valid transitions:**
```
pending    → confirmed | cancelled
confirmed  → packed | cancelled
packed     → out_for_delivery | picked_up | cancelled
out_for_delivery → delivered | cancelled
delivered  → completed
picked_up  → completed
```

**Cancellation:** Restores stock if order was `confirmed` or `packed`.

**Errors:**
| Code | Error | When |
|---|---|---|
| 422 | `ORDER_INVALID_STATUS_TRANSITION` | Invalid transition |
| 404 | `ORDER_NOT_FOUND` | Unknown order_id |

## Payments

### POST /api/payments/webhook
Razorpay sends payment confirmation here. **Do not call manually.**

**Access:** Razorpay servers only (HMAC-SHA256 verified)

**Headers:**
```
X-Razorpay-Signature: hmac_sha256_hex_of_body
Content-Type: application/json
```

**Request body:** Razorpay webhook payload (event=`payment.captured`)

**Response 200:** `{"status": "ok"}` — always fast, background tasks run after.

**Errors:**
| Code | Error | When |
|---|---|---|
| 400 | `WEBHOOK_SIGNATURE_INVALID` | HMAC verification failed |
